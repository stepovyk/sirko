# Сірко – правила проєкту

Власний шаховий рушій на Rust, без чужого рушійного коду й без залежностей. Грає на Lichess окремим ботом SirkoAI.

- Мова – Rust (edition 2021, `rust-version = 1.75`: так він збирається системним cargo з Ubuntu 24.04 без rustup). Залежностей немає й не додавати, Cargo.lock не зберігається.
- Модулі: `bitboard` (магічні числа шукає сам на старті), `position` (копіювання позиції на хід, рокіровка – «король бере свою туру», поле на проході – лише для легального взяття), `search` (PVS, Lazy SMP, таблиця `tt` без блокувань), `eval` (ручна оцінка), `nnue` (власна мережа, покрокові накопичувачі), `see`, `uci`, `datagen` (самогра), `train` (власний тренер).
- Мережа: `nets/sirko.nnue` вбудовується при збиранні (`build.rs`), без неї – ручна оцінка; `EvalFile` – перевірка нової мережі без перезбирання (`<hce>` – ручна оцінка). Нова мережа чи зміна пошуку йде в main, лише коли виграє матч у попередньої версії (`tools/match.py`), результат – у README.
- Генерація ходів: будь-яка зміна – perft (`cargo test`, `sirko perft 6` = 119060324) і звірка з python-chess (`tools/movegen_check.py`). UCI – `tools/uci_check.py` (мати, ponder, шахи Фішера, партія сам із собою). Усе це робить CI (`.github/workflows/check.yml`) на x86 і ARM.
- Перед пушем: `cargo fmt`, `cargo clippy --release --all-targets -- -D warnings`, `cargo test --release`, обидві перевірки з `tools/`.
- Перевірка змін: `test.yml` (версія проти main, 8 машин; 300 партій на машину = 2400), злиття при LOS ≳95%, повтори можна об'єднувати. Сила – `strength.yml` проти свіжого Stockfish з UCI_Elo 3190, щотижня сама.
- Самонавчання: `train.yml` щосуботи сам – самогра поточною мережею, навчання етапами (`--state`, до трьох машин по ~5,5 год) на новій і свіжій самогрі з main (~1 млрд позицій, 512 нейронів, 10 епох), матч 4800 партій; при LOS ≥97,5% мережа сама йде в main (коміт від github-actions), тож перед пушем – `git pull --rebase`.
- Не дали сили (не повторювати без нової ідеї): ProbCut, razoring, відсічення за історією, 4-та історія продовжень, бонус історії за відсічення з таблиці, бонус ходу суперника при провалі вузла, усереднення оцінки при відсіченні й у зворотному відсіченні, сильніше скорочення в cut-вузлах без ходу з таблиці, час за часткою вузлів кращого ходу й за падінням оцінки, мережа на 384 нейрони з більшими даними.
- Протокол: на `go ponder`/`go infinite` відповідь лише після `stop` чи `ponderhit`; на кожен `go` – рівно один `bestmove`.
- Тексти – українською, без довгого тире.
